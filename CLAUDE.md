# Claude Instructions

Before making changes:

1. Read `index.md`.
2. Read `rules.md`.
3. If changing `app/` or `ui/`, read that workspace's nearest `index.md` and `rules.md`.

Follow the project rules for settings, bearer authentication, CORS, Prisma migrations, DTO/API/use case file granularity, handoffs, and smoke testing.

After a successful smoke test, commit the change set unless the user explicitly asks not to.
